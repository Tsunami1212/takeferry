# Changelog

## 0.1.0-alpha.2 (2026-11-27)

A writer can compare takes from eight additional video routes and export the scene as an editable storyboard. The connector catalog distinguishes native video nodes, saved-workflow outputs, canvas assets, job media and planning boards. The portable app can export the entire Hermes skill with eight licensed upstream guides. The expanded rehearsal exercises each video route with synthetic receipts. [Canvas guide](docs/canvases.md) · [Verification details](docs/verification.md)

## 0.1.0-alpha.1 (2026-11-27)

First public source preview. The English Hermes skill directs shots on native video canvases. The local MCP server keeps takes and revisions together, binds Pippit media to the chosen native node and records LibTV receipts supplied by the official connector. The rainy-door example includes original storyboards and can run from a single Python application file. [Verification status](docs/verification.md)
