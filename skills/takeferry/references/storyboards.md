# Put the scene on a board

Start with the writer's approved shot order. For each shot, give `takeferry_storyboard` a stable `shot` ID and a visible `beat`. Add a camera direction and the names and jobs of any references. A new scene can have a board before its first take. After a rehearsal or shoot, the same call adds recorded takes, revision parents and the selected edit points. Use a different name for each reference in a shot.

Choose the destination with the writer. The board includes the supplied scene text, reference labels and creative notes. Send those only to the board they chose. The export omits account IDs, local media paths, approval digests and raw provider receipts.

- **Obsidian or another JSON Canvas editor.** Use `format: canvas` for a JSON Canvas 1.0 document. Save it as a new `.canvas` file. Each shot, reference and take has a stable card ID. A new export can go beside a manually arranged board. [Bundled Obsidian skill](upstream/obsidian/json-canvas/guide.md) · [File format](https://jsoncanvas.org/spec/1.0/)
- **FigJam.** Use `format: mermaid` and the official `generate_diagram` tool. Read its current schema for the file destination and accepted Mermaid subset. If the user wants to change an existing diagram, use native FigJam editing tools available in their session and preserve unrelated items. Read the result and return the file link. [FigJam skill](https://github.com/figma/mcp-server-guide/blob/5e4790847aedd4312fff65a11f7695c9c9382be0/skills/figma-use-figjam/SKILL.md) · [Diagram tool](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/)
- **Miro.** Use `format: cards`. Ask `canvas_get_canvas_composer_skill` for the current SVG contract and read the target area with `canvas_read_as_svg`. Map cards and links to the documented items. Use `canvas_create_from_svg` for a new area. For a revision, use `canvas_update_from_svg` with the IDs returned by Miro. Read back the edited area and return the board link. [Miro canvas tools](https://developers.miro.com/docs/miro-mcp-tools)
- **Canva.** Use `format: cards` for an editable shot deck. Check the design and page IDs. Put each beat, camera direction and reference duty on its intended page. Start an editing transaction, perform the supported operations, preview, then commit or cancel. Reread the committed design and return its link. A storyboard edit does not authorize a video render. [Canva editing tools](https://www.canva.dev/docs/apps/mcp/tools/)
- **Excalidraw.** Use `format: cards`. Read `read_me` on the official server, turn the cards and links into its supported elements and call `create_view` in an MCP Apps viewer. Keep the latest checkpoint ID when revising. A public share link requires a separate sharing decision. [Excalidraw MCP](https://github.com/excalidraw/excalidraw-mcp)
