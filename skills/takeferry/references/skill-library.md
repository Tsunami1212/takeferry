# Canvas skills in this package

The following eight guides ship as reference material inside the directing skill. Open the guide for the current job. The writer's approval applies to the displayed take, including a zero-price or unknown-price run. An upstream suggestion to retry or make extra versions needs a new decision whenever it would submit another paid job.

Each guide keeps its original text. The entry files are named `guide.md` so Hermes loads them as references to TakeFerry. The manifest records the original paths, revisions and SHA-256 hashes. Each publisher's MIT license sits beside its guides. [Source manifest](upstream/index.json)
